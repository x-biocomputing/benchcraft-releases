# BenchCraft

A laboratory programming workspace by CogWorks, with AI assistance and PyLabRobot. This repository distributes preview installers.

- [macOS — Apple silicon](https://github.com/x-biocomputing/benchcraft-releases/releases/download/v0.0.2/benchcraft-desktop-mac-arm64.app.tar.gz)
- [Windows — x64](https://github.com/x-biocomputing/benchcraft-releases/releases/download/v0.0.2/benchcraft-desktop-win-x64.exe)
- [Linux — Ubuntu 24.04 x64](https://github.com/x-biocomputing/benchcraft-releases/releases/download/v0.0.2/benchcraft-desktop-linux-amd64.deb)

[Installation notes, checksums and build details](https://github.com/x-biocomputing/benchcraft-releases/releases/tag/v0.0.2)

Open BenchCraft and sign in with Google or an email code. Your verified account receives **$50 in one-time testing credits** automatically. No invitation or payment details are required to start.

Subscriptions, one-time top-ups and account access are available at [benchcraft.cogworksai.com](https://benchcraft.cogworksai.com). You can also use your own supported model provider.

The Windows preview is unsigned; the Mac preview is not notarized. Installation and native software checks cover macOS, Windows Server 2025 x64, and Ubuntu 24.04 x64. Consumer Windows and physical-instrument acceptance remain separate. Instrument compatibility depends on the PyLabRobot driver and your lab setup.

Beta 0.0.2 automatically sends bounded diagnostics during normal use, without review or sharing steps. See the [privacy notice](https://benchcraft.cogworksai.com/privacy.html) for scope, retention and controls.
